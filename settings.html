ST-State-Manager
While disabled, the extension does not call any model and does not modify the chat.
Model call
Connection Manager is disabled, so only the main SillyTavern connection is available.
State updates use a separate, non-streaming request and do not add chat messages.
Automatic updates
Off by default. When enabled, automatic updates and swipe updates make paid requests using the connection above.
Swipes do not advance the user-message counter. A new swipe is read after it finishes; an existing swipe is read when selected.
State in the main prompt
Depth 0 is the end of the context. Merging applies to chat completion; the provider's own prompt processing may also merge messages.
Worker prompt & history
Variables: {{state}}, {{last_messages}}, {{history}}, {{chat_name}}, {{char_name}}. Return a full JSON object; invalid responses leave the state unchanged.
